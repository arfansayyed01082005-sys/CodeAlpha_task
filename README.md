# Python Programming Tasks – Common Project

## 📌 Overview

This project is a collection of simple Python programs created to improve understanding of fundamental programming concepts. Each task focuses on basic logic building and problem-solving skills.

All programs are written in Python and run in the command line (console). No external libraries are required, which makes them easy to execute on any system with Python installed.

##  The project included are: 

Task 1: Hangman Game

Task 2: Stock Portfolio Tracker

Task 4: Basic Chatbot

Each task is stored in a separate Python file for better organization and clarity.

# 🧩 Task Details

# ✅ Task 1: Hangman Game

## Description:

This is a console-based word guessing game. The program randomly selects a word from a small list. The player must guess the word by entering one letter at a time. The player gets only a limited number of wrong attempts.

## Features:

Randomly selects a word from a list

Shows hidden word using underscores

Tracks guessed letters

Allows maximum 6 wrong guesses

Displays final win or lose message

## Concepts Used:

Random selection: Chooses a word automatically from a list.

Looping (while loop): Keeps the game running until the player wins or loses.

Decision making (if-else): Checks whether the guessed letter is correct or wrong.

String processing: Compares letters with the secret word.

List usage: Stores guessed letters to avoid repetition.

User interaction: Takes input from keyboard and prints output.

# ✅ Task 2: Stock Portfolio Tracker

## Description:

This program helps users calculate the total value of their stock investments. The user enters stock names and quantities, and the program calculates the total investment based on predefined prices.

## Features:

Stores stock prices in a dictionary

Accepts stock name and quantity from user

Calculates total cost automatically

Displays summary of total investment

Simple and interactive console interface

## Concepts Used:

Dictionary: Stores stock names and their prices in key-value format.

Looping: Allows user to enter multiple stocks.

Mathematical calculations: Multiplies price by quantity.

Conditional checking: Verifies if entered stock exists.

Input/output: Communicates with the user.

Basic validation: Prevents invalid stock names.

# ✅ Task 4: Basic Chatbot

## Description:

This is a simple rule-based chatbot that responds to predefined user messages. It can reply to greetings and exit when the user types “bye”.

## Features:

Responds to common greetings

Understands simple fixed commands

Runs continuously until exit command

Displays friendly responses

Example Inputs:

hello  

how are you  

bye

## Concepts Used:

Conditional statements (if-elif-else): Matches user input with predefined replies.

Functions: Organizes chatbot logic into a reusable block.

Loop (while loop): Keeps the chatbot active until the user exits.

String comparison: Converts input to lowercase for matching.

Keyboard input & screen output: Enables interaction.
