**CodeAlpha Python Programming Internship – Task 4**



**Task Name**



Basic Chatbot



**Description**



The Basic Chatbot is a simple rule-based conversational program developed using Python.

It interacts with users by responding to predefined inputs such as greetings and common questions.



The chatbot uses conditional statements (if-elif), functions, loops, and basic input/output operations to simulate a conversation.



This project helps in understanding the fundamentals of chatbot logic and control flow in Python.



**Functionality**



* Accepts user input from the keyboard



* Recognizes specific keywords such as:



&nbsp; • "hello"



&nbsp; • "how are you"



&nbsp; • "bye"



* Provides predefined responses



* Runs continuously in a loop until the user types "bye"



* Displays appropriate responses based on input



**Concepts Used**



* if-elif-else statements



* Functions



* While loop



* User input (input())



* Output display (print())



* String comparison



* Basic rule-based logic



**How to Run**



1. Install Python on your system



2\. Open terminal or command prompt



**3. Run the program using: python chatbot.py**



**Example**



Input: hello

how are you

bye



Output: Hi! Nice to meet you

I'm fine, thanks for asking

Goodbye! Have a great day
